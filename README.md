# 香港海事数据枢纽 V3 · 使用说明

**在 V2 基础上新增 Cesium「智能地图」**：默认空白香港海域三维地球，右侧勾选图层后逐步叠加岸线影像、限速区、潮位/风/能见度站与海洋预报点。V2 的目录、最新数据连接器、SVG 限速区预览均保留；**本目录为独立 V3，不覆盖 V2 文件夹。**

## 推荐启动（Mac / Linux）

进入本文件夹后运行：

```bash
python3 server.py
```

需要 Python **3.10 或以上**。浏览器打开：

```text
http://127.0.0.1:8765
```

左侧选择 **智能地图**。三维地球与 OSM 瓦片需要联网；测站实时数值建议通过本地服务读取（避免 CORS）。换端口：

```bash
python3 server.py --port 8766
```

也可使用 `启动网站-Mac.command` / `启动网站-Windows.bat`。

## 智能地图（V3）

- **默认**：深蓝空白海域，相机对准香港水域，无业务图层。
- **右侧勾选**：岸线/影像底图、限速区 SRZ（47）、潮位站、风测站、能见度站、海洋预报点。
- **一键铺满 / 清空**：按序渐显或清空回空白海域。
- **点击要素**：查看限速规则或站点读数摘要；可跳转「最新数据」打开对应连接器。
- **技术**：CesiumJS（CDN，无 Ion Token）；测站坐标见 `source/stations_geo.json`（研究用近似位置，非官方海图）。

直接双击 `HK_Maritime_Hub_V3.html` 也可打开；智能地图仍需联网加载 Cesium。部分 CSV/XML 源站有跨域限制时请使用 `server.py`。

## 页面功能（继承 V2）

- **数据目录**：31 项海事资料入口。
- **最新数据**：19 个独立查询连接器。
- **非直连资料**：接入限制分类说明。
- **限速区预览**：原 SVG 交互地图（与智能地图并存）。
- **开源工具 / 简介**：仓库入口与 MD 导出。

## 文件

| 路径 | 说明 |
|------|------|
| `HK_Maritime_Hub_V3.html` | 主页面 |
| `source/smart_map.js` / `.css` | 智能地图逻辑与样式 |
| `source/stations_geo.json` | 测站近似坐标 |
| `server.py` | 本地只读网关（含 `/source/*` 静态白名单） |
| `feeds.json` / `catalog.json` | 连接器与目录 |

修改 `feeds.json`、`catalog.json` 或两份 MD 后运行 `python3 sync_registry.py`（只更新 HTML 内嵌注册表，不改智能地图代码）。

## 安全与边界

本服务是本机、只读、固定源白名单网关。智能地图仅供研究资料展示，**不能作为航行或安全决策系统**。无 AIS、无官方 ENC、无 Ion 商业影像订阅。

直接放到公网前需配置域名、TLS、访问控制与限流。
